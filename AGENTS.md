# Website Agent Rules

## Read first

**Business rules:** [`../docs/CANON.md`](../docs/CANON.md). Since 1 November 2026 the site carries six programmes only: Pulse, Pulse+, Corridor, Boda Hub, wireless EV charging research and the Agent Harness, with Lipa Pole Pole as Pulse financing. Spark, Pod energy storage, Depot and the modular energy family are retired.

**UI system:** [`docs/UI.md`](docs/UI.md)

**Pivot inventory:** [`docs/PIVOT-CLEANUP.md`](docs/PIVOT-CLEANUP.md)

Passenger-booking agent docs are **archived**. Do not restore `/book`, seat maps or booking APIs as live product.

## Scope

Maintain the public charging site:

- Charging Hub (`/hub`)
- Programme pages (`/charging`, `/charging/home`, `/charging/pulse-plus`, `/charging/corridor`, `/charging/boda-hub`, `/research`, `/ai`)
- Precifarm Agent (`/download`)
- Sustainability (`/sustainability`)
- Training, partners, SEO surfaces

## Source of truth

- Copy: `lib/brand-messaging.ts`, `lib/charging-hub.ts`, `lib/download-page.ts`, `lib/home-charging.ts`
- CMS: SEO, contact, analytics when `CMS_API_URL` is set
- Demo stores are not traction
- Live vs planned hubs stay honest
- Programme ratings come from `lib/generated/product-specs.ts`, generated by PRECIFARM_MASTER `tools/pfm.py export-web`; do not type ratings by hand
- Corridor DC has no public price until a site is commissioned and costed
- Precifarm Agent is not a chatbot

## Copy

- From home charging to highway charging, plus private AI
- Full product names (Pulse charger, Pulse+ charger, Corridor charging, Boda Hub)
- Open Charging Hub — not Book Now
- Nairobi–Kisumu is the first Corridor, not a bus timetable
- Planning assumptions are not traction

## Deploy

Production: **Google Cloud Run** (`europe-west1`). See [`docs/DEPLOY-GCP.md`](docs/DEPLOY-GCP.md).

**Secrets:** copy [`.env.example`](.env.example) → `.env.local`. See [`docs/infrastructure/environment.md`](../docs/infrastructure/environment.md).

## Required checks

Run lint and build. Confirm `/book` still redirects to `/charging`. Confirm `/download` does not claim a chatbot, Play Store or iOS.
